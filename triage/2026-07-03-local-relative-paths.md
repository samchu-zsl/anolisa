## 输入摘要

文档库中不应写死用户机器上的绝对路径。文档库内部引用应使用相对路径，用户 home 下的 skill 链接用 `~/.agents/...` 或 `~/.codex/...` 表达。

## 证据

- 多个流程文档、spec、design、ADR 和 skill 测试记录中存在用户机器上的绝对路径。
- 根 README 中存在代码仓库绝对路径。

## 影响范围

- 文档库路径引用。
- skill references 和测试记录。

## 分诊判断

类型为 chore，复杂度 low。该变更不改变流程语义，只修正路径表达方式。

## 推荐路径

直接修正文档并用搜索命令验证无仓库内绝对路径残留。

## 后继要求

- 文档库内部引用使用相对路径。
- skill 必须显式约束文档库内部引用使用相对路径。
- 不改动代码仓库。

## 验证建议

- 搜索用户目录绝对路径模式，确认没有残留。

## 验证结果

- 已确认文档库中没有用户目录绝对路径残留。
- 文档库内部引用已改为相对路径。
- skill 已补充相对路径约束。
