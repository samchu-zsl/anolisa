## 问题

Rust 1.97 Clippy 对 `format!` 参数上的显式引用新增或启用了更严格检查：

```rust
let bypass_tool_use_id = format!("{}-bypass", &tc.id);
```

`format!` 会自动借用参数，因此 `&tc.id` 是冗余引用。在 `-D warnings` 下，
该 lint 阻断整个 `Test cosh-ng` job。

## 复现或证据

- RED：PR #1426 GitHub Actions 的 `cargo clippy --workspace --all-targets --
  -D warnings` 在 Rust 1.97 上退出 101。
- lint：`clippy::useless_borrows_in_formatting`。
- 本机 Rust/Clippy 1.91 运行相同命令为 GREEN，说明版本差异是本地未复现原因，
  不能替代 Rust 1.97 CI 的最终验证。
- `rg` 只找到这一处 `format!("{}-bypass", &tc.id)`。

## 影响范围

- 生产代码：`crates/cosh-core/src/core.rs` 一行。
- 提交：在现有 PR 分支新增独立
  `fix(cosh-ng): [core] drop redundant format borrow` commit。
- 不修改 #1361 的 svc dry-run commit、测试、公共类型、依赖或 lockfile。

## 初步根因

旧版本 Clippy 没有拒绝该写法，主线因此保留了语义正确但冗余的显式 borrow。
CI 跟随 stable 升级到 Rust 1.97 后，同一代码成为 hard lint failure。

## 诊断判断

删除 `&` 后，`format!` 宏仍以借用方式格式化 `tc.id`，不会移动字段；后续
`tc.id` 使用保持有效，生成字符串完全相同。这是单点、无行为变化的小修。
